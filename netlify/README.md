# Netlify で公開するためのファイル

GAS のウェブアプリ（管理画面・お客様ページ）を、このサイトの中に埋め込んで出す。
GAS のURLを直接開くと上に出る「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」の帯は、埋め込んだ画面では出ない。

## 公開の手順

1. GAS に v0.141.0 以降のファイルを貼り、デプロイを「新しいバージョン」で更新する（埋め込みを許すのは v0.141.0 から）。デプロイのアクセスできるユーザーは「全員」のまま。
2. `config.js` の `GAS_URL` に、ウェブアプリのURL（`https://script.google.com/macros/s/…/exec`）を入れる。
3. このフォルダー（`netlify`）を Netlify に公開する（Netlify の「Add new site」→「Deploy manually」に、フォルダーごとドラッグ＆ドロップ）。
4. GAS のURLを直接開いて管理者でログインし、設定の「会社と画面」→「公開サイトのURL」に Netlify のURL（例：`https://xxxx.netlify.app/`）を入れて保存する。
   - 入れる前に Netlify のサイトを開くと、「決められたサイトからだけ開けます」と出る（ほかのサイトに勝手に埋め込まれないための仕組み）。
5. Netlify のURLを開いて、ログインできることを確かめる。

## 入れておくとよいこと

- 「公開サイトのURL」を入れると、お客様ページのURL（`https://xxxx.netlify.app/?t=…`）と、毎朝の通知メールのリンクが Netlify のサイトになる。前に渡したお客様ページのURL（GAS のURL）も、そのまま使える。
- 収集ツールの送り先は、今までどおり「ウェブアプリURL」（GAS）。変えなくてよい。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面いっぱいに GAS の画面を埋め込む |
| `config.js` | GAS のURL・タブに出す名前（ここだけ直す） |
| `site.js` | `?t=` が付いていたら、お客様ページを開く |
| `site.css` | 見た目 |
| `favicon.svg` | タブのアイコン |
| `_headers` | Netlify のセキュリティの設定（このサイトをほかのサイトに埋め込ませない、など） |

## 気をつけること

- ログインの「ログインしたままにする」・入力の途中の下書きは、ブラウザがサイトごとに分けて残す。GAS のURLで覚えていたものは引き継がれないので、Netlify のサイトで一度ログインし直す。iPhone の Safari は、しばらく開かないと消すことがある。
- 音声入力（マイク）は、ブラウザによっては埋め込んだ画面の中で使えないことがある。
- 帯が出ないのは、Google の今の動きに合わせたもの。Google が変えたら、また出ることがある。
